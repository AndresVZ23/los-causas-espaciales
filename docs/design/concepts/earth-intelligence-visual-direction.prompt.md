# Procedencia del concepto visual

Concepto generado como tablero de dirección visual, no como captura de una interfaz terminada.

## Prompt

Create a high-fidelity visual direction board (not a finished webpage mockup) for “Los Causas Espaciales”, a Spanish-language Earth intelligence and investment analysis web application. The board should establish a premium dark operational design language inspired by a nighttime remote-sensing interpretation table: graphite-black mineral surfaces, subtle elevation through lightness only, crisp 1px rules, sparse mineral-cyan selection lines, white and cool-gray typography, tabular monospaced numerals, tiny cartographic registration ticks, restrained false-color satellite swatches, and one signature acquisition-line motif moving along a map edge. Show component fragments and material samples: compact icon rail, selected navigation line, standard filter fields, provenance labels for REAL_DATA / CACHED_DATA / USER_ASSUMPTION / DATA_UNAVAILABLE, a clean map legend, an accessible time-series chart fragment with scales and dates, a pipeline progress strip, and responsive mobile adaptation. No gradients, no glassmorphism, no neon glow, no marketing hero, no fake commercial claims, no decorative dashboard card grid, no invented metrics. Spanish labels may appear only as short component labels. Editorial quality, precise technical interface craft, 16:10 landscape composition.

## Uso

La imagen orientó materialidad, jerarquía, densidad, color, navegación y procedencia. Los datos dibujados en el concepto no se trasladaron a la aplicación. Toda cifra operativa de la interfaz proviene del backend o de supuestos explícitos del usuario.
