# Demo Scenarios

## Renewable energy — Moquegua and Arequipa

Select solar irradiance and the 2001–2024 period. Run a point analysis for Moquegua, then use Comparative Analysis to retrieve the same variable and period for Moquegua and Arequipa. Verify provenance, annual series, Sen slope, p-value, completeness, and raw summary statistics. This is a resource-screening result, not a feasibility study.

## Road corridor foundation

Paste a WGS84 LineString in the GeoJSON panel. The current version validates the geometry and calculates geodesic length. NASA sampling and hazard overlays along the corridor remain pending; the interface does not represent them as complete.

## Real-estate site foundation

Paste a WGS84 Polygon in the GeoJSON panel. The current version validates the polygon and reports area, perimeter, centroid, and bounding box. Terrain, hazard, environmental, archaeological, and legal layers must be integrated before a territorial assessment is issued.

## Investment scenario

Enter CAPEX, revenue, OPEX, mitigation CAPEX, interruption cost, discount rate, and horizon. The engine returns NPV from those assumptions only. It does not estimate disaster probability, market demand, asset value, or expected loss.

Numerical NASA results are not hard-coded here because the source API is updated. They are reproduced live and cached with provenance and retrieval time.
