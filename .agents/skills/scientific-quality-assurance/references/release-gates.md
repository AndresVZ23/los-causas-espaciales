# Puertas de liberación y fuentes

## Evidencia mínima por cambio

| Tipo | Evidencia mínima |
|---|---|
| NASA | respuesta oficial validada, metadatos y caso de error |
| Estadística | dataset controlado, contraste independiente y tolerancia |
| Geoespacial | CRS/ejes/unidades, geometría válida y caso límite |
| Finanzas | supuestos, fórmula, flujo independiente y sensibilidad |
| Frontend | build, interacción, consola, screenshot desktop y mobile |
| Seguridad | auditoría de dependencias, secretos y validación de entrada |

## Fuentes institucionales

- NASA Data Use and Citation: https://www.earthdata.nasa.gov/engage/open-data-services-software/data-use-policy
- NASA Data Quality recommendations: https://www.earthdata.nasa.gov/s3fs-public/imported/ESDS-RFC-034.pdf
- NASA Common Metadata Repository: https://www.earthdata.nasa.gov/about/esdis/eosdis/cmr
- NIST reproducibility in research: https://doi.org/10.6028/jres.124.024
- OWASP Application Security Verification Standard: https://owasp.org/www-project-application-security-verification-standard/

Las fuentes informan el proceso; la aceptación depende además de evidencia producida por el repositorio.
