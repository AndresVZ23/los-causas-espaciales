# Geometrías públicas de pilotos

`moquegua_ilo_osm.geojson` es una instantánea simplificada del corredor vial Moquegua–Ilo. La ruta fue calculada el 23-oct-2026 con el servicio Route de OSRM (`overview=simplified`, `geometries=geojson`) entre puntos públicos próximos a ambas ciudades. El resultado declaró 89.157 km y se dividió en cinco tramos contiguos sin alterar sus vértices.

Datos viales: © OpenStreetMap contributors, disponibles bajo ODbL 1.0. Atribución y licencia: https://www.openstreetmap.org/copyright. OSRM solo calculó la ruta sobre esos datos.

Es una geometría de screening y demostración, no un eje oficial del MTC, levantamiento topográfico, inventario de puentes ni diseño vial. Debe actualizarse o sustituirse por una geometría oficial antes de prefactibilidad. No contiene datos de clientes.
